# Crew 0.5.1 — Windows preview

2026-10-21 · Native Windows x86_64 MSVC · Pre-release

This release adds a Windows preview to the 0.5 series. It contains a native
portable ZIP and an unsigned Inno Setup installer. The installer is built, but
its full install/upgrade/downgrade/uninstall lifecycle is not certified.
The existing 0.4.0 stable release and 0.5.0 Linux preview remain unchanged.

## Changes

- Execute one-time PowerShell/pwsh workspace and tab startup commands after shell
  initialization through native argv. Keep the shell interactive, cwd/env intact,
  and avoid replaying commands on split or cold restore.
- Load Authenticode verification from Windows PowerShell's own Security module,
  preserving the pinned Inno 7.1.0 digest, publisher and engine-version checks.
- Add optional one-line `sidebar_pane_segments`: literal metadata templates,
  strict RGB foregrounds and per-segment bold/dim overrides. API/TUI share the
  projection; empty values fall back and complete output stays bounded.
- Keep temporary-directory cleanup strict while waiting briefly for Windows
  sharing locks, and require complete nonce-framed fields in live transfer probes.

## Validation boundary

The release uses local native Windows verification, with source/binary/log
digests in the attached release manifest and native summary. It does not use
GitHub-hosted runners. CI and Release workflows remain disabled.

The unchanged product code previously passed 393 Windows Rust tests, 11 release
tooling tests, 21 local tooling tests, 12 product smoke suites and native Inno
compilation. The versioned release source is rebuilt and those 25 executable
canonical commands must pass again before publication. The attached summary
records the final source identity and results.

The required installer lifecycle is **BLOCKED**, not PASS. Windows App Control
denied process creation of the pinned released Crew 0.3.0 `tmuxlike.exe --version`
with WinError 4551. No security setting is changed and the denied operation is
not retried or bypassed. A previous 0.5.0 local candidate completed five of the
14 lifecycle checks; those results do not certify this new installer.

The user's successful manual run of the earlier local Windows build is recorded
separately. It does not replace automated release-source tests or the remaining
installer lifecycle. Linux/macOS native execution for 0.5.1 is NOT_RUN.

This is a manual, explicitly authorized preview publication. The strict
`package_local.py` full-evidence gate remains unchanged and has not passed.
The public native summary is a coverage report, not complete validator evidence.

## Download and use

- Portable ZIP: extract to a new directory, then run `crew.exe`. Add that directory
  to your user PATH if desired; preserve any existing PATH entries.
- Setup: per-user, unsigned Inno build. Its full lifecycle is still blocked as
  described above; it does not automatically modify PATH.
- Check `RELEASE-SHA256SUMS` against every downloaded asset. Package sidecars
  identify the actual source commit/tree and embedded payload digests.

One-line styled labels are a bounded Herdr-inspired subset. Multiple rows/grids,
conditional rules, single-pane or cross-host PTY moves, remote pane embedding,
Herdr plugin ABI/hooks/renderers, semantic screen-state detection and advanced
graphics terminal protocols remain outside this release.

## Next installer validation

permits the exact pinned legacy fixture. Do not weaken the 5900X's settings or
bypass its denial. Re-run the canonical validator and all 14 lifecycle checks in
